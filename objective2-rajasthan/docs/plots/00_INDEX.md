# Plot Index — Phases 2–8 (Rajasthan)

Generated by `src/plots/make_plots.py`:
```
python pipeline.py --state rajasthan --stage plots
# or: python -m src.plots.make_plots rajasthan
```
Needs `plotly` + `kaleido` (already installed). Every figure is saved
twice under `results/plots/`:
- `interactive/<name>.html` — **open this one first.** Fully
  self-contained (no internet needed), opens in any browser by
  double-clicking. Hover for exact values, drag to zoom, click legend
  entries to toggle. Git-ignored (large — inlined plotly.js).
- `static/<name>.png` — the same figure as a flat image, for a report,
  slide deck, or printed viva material. Committed.

Nothing in these plots is a mockup — each is generated from files Phases
2–8 already produced (`phase5_design_cases.parquet`,
`phase7_optimized_designs.csv`, `phase6_surrogate_models.pkl`,
`phase8_robustness.csv`, …), or from re-running one specific
already-verified case through the real simulator to get a time series.
Re-run `--stage plots` after any phase changes to regenerate every figure
from the current results.

`src/plots/make_plots.py` is ported from `objective2-tamilnadu/`; the
figure code is unchanged, only the flat `results/phaseN_*` input paths,
the 3-regime subplot grids (TN has 5), Rajasthan's PCM names, and the
title-string case counts differ.
