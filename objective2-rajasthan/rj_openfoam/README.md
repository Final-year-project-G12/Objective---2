# rj_openfoam — OpenFOAM/ParaView recalibration and validation of O2 (Rajasthan, v3)

Status (2026-10-29): **run up to the literature benchmark and stopped there.** The CFD does not reproduce Tan et al. 2009
and the mesh study is not converged, so no design-capsule run or fit was done. Nothing in the O2 results depends on this
folder. Full account: `../docs/07_OPENFOAM_VALIDATION.md`.

## Why
The O2 simulator models each capsule as one lumped node with resistance `r/(5k)` and a
liquid-convection factor of 2.0 once melt fraction ≥ 0.5 — both assumed, not measured (report §3.6).
G22 showed F = 1…4 moves g_window by at most 13.7 kWh (inside the bands), but no CFD has checked the
constants for the chosen capsules (R ≈ 40 mm). This folder adds that check (plan item WP2-C).

## Method
* One spherical capsule, 2-D axisymmetric wedge (5°), gravity along the axis (vertical tank).
* Enthalpy-porosity: `solidificationMeltingSource` (Carman-Kozeny momentum sink + latent source),
  Boussinesq liquid. OpenFOAM-ESI: `buoyantPimpleFoam` + `system/fvOptions`;
  OpenFOAM.org v11/12: `foamRun -solver fluid` + `constant/fvModels` (set in `configs/rj_cases.yaml`).
* Melting band Tm ± 1 K, same as the simulator. Constrained melting (solid held in place), no volume change.
* Ladder: R2 mesh study → **V0** Tan et al. 2009 n-octadecane sphere benchmark → design capsules
  (charge 70 C, charge 62 C, discharge to mains, convective charge) → fit `c`, `F` → re-score
  O2 on explore/select years only (held-out lock untouched).

## Layout
| Path | What |
|---|---|
| `configs/rj_cases.yaml` | v3 designs, scenarios, PCM properties (null until copied from the repo PCM database) |
| `scripts/make_capsule_case.py` | writes a full case (mesh, thermo, fvOptions/fvModels, BCs, function objects, Allrun) |
| `scripts/calibrate_lumped.py` | OpenFOAM melt fraction vs lumped model, grid fit of (c, F) → `results/calib_*.csv/png` |
| `postprocess/paraview_capsule.py` | pvpython: alpha1 / T snapshots and alpha1 = 0.5 front CSVs |
| `PROMPT_OpenFOAM_Recalibration.md` | the Claude Code prompt that runs steps R0–R8 |
| `scripts/run_batch.py`, `run_wsl.sh` | generate + run several cases in WSL (paths with spaces break OpenFOAM, so runs happen in `~/rj_runs`) |
| `scripts/case_summary.py`, `v0_compare.py`, `stefan_sphere_1d.py` | t50/t90 + energy check; V0 table; 1-D conduction reference |
| `cases/` (ignored by git), `results/` | `cases/` regenerated by `run_batch.py`; `results/` holds the compact data of every run |

## Run one case
```bash
python scripts/make_capsule_case.py --design r0 --scenario charge_70     # refuses while properties are null
cases/r0_charge_70_n40/Allrun
pvpython postprocess/paraview_capsule.py cases/r0_charge_70_n40
python scripts/calibrate_lumped.py cases/r0_charge_70_n40
```

## Known limits
Single-phase solver uses density_solid (mass-consistent with the simulator), averaged k, cp; melting is isothermal at Tm (one `Tmelt` in the ESI option). No supercooling, no unconstrained (sinking-solid) melting,
no capsule-to-capsule interaction; agreement is model-to-model.
