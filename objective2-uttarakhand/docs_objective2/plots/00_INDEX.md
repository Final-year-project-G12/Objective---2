# Plot Index — Phases 2–8 (Uttarakhand)

Generated by `src/plots/make_plots.py` — run with:
```
python -m src.plots.make_plots uttarakhand
```
Every figure is saved twice under `results/uttarakhand/plots/`:
- `interactive/<name>.html` — **open this one first.** Fully self-contained
  (all JS inlined, no internet needed), opens in any browser by double-clicking.
  Hover over any point/bar for exact values, zoom by dragging, pan, and
  toggle legend entries by clicking them. This is the interactive "live" version.
- `static/<name>.png` — the same figure as a flat image, for pasting into
  a report, slide deck, or printed viva material.

Nothing in these plots is a mockup — every one is generated directly from
files Phases 2–8 already produced (`design_cases.parquet`,
`optimized_designs.csv`, `deployable_design_per_regime.csv`,
`robustness_summary.csv`, the trained surrogate, etc.), or from running
specific, deterministic cases through the real simulator. Re-running
`make_plots.py` regenerates every figure from the current results.
